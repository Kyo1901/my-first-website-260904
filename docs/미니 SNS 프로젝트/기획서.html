트랙핏 (TrackFit)

자신들만의 운동 기록을 공유하는 SNS · 운동 장소 공유 및 목표 지정·달성이 핵심 가치

1서비스 기본 정보

서비스 이름트랙핏 (TrackFit)
서비스 주제자신들만의 운동 기록을 공유
핵심 가치운동할 장소 공유 및 자신의 목표 지정 및 달성
타겟 사용자20~40대

2디자인 컨셉

메인 색상style_theme (Material 3 기반, Primary #415F91 블루 계열) — light.css / dark.css로 라이트·다크 모드 모두 정의
전체 분위기깔끔하고 전문적인 분위기
참고 사이트인스타그램, X(구 트위터)
접근성 지원라이트/다크 각각 표준·중간대비(-mc)·고대비(-hc) 3단계 테마 제공

실외에서 운동하며 사용하는 서비스 특성상 햇빛 아래 가독성을 위해 설정(마이페이지)에서 고대비 모드를 선택할 수 있게 노출을 권장합니다.

3필요한 페이지 목록

1 로그인/회원가입 페이지

기능

  • 이메일 + 패스워드 로그인
  • 이메일 회원가입(이메일 인증 X)
  • 닉네임(이름)
  • 생년월일(만 14세 미만 가입 금지)
  • 자동 로그인(토큰 저장)
  • 비밀번호 재설정(이메일 링크 발송)
  • 이용약관/개인정보처리방침 동의 체크박스

특징

  • 회원가입 후 로그인 페이지에서 로그인 시도
  • 로그인 성공 시 메인 피드로 이동
  • 최초 실행 시 간단한 온보딩(2~3장) 노출
2 메인 페이지 (홈 화면)

기능

  • 팔로잉 기반 피드 - 최신순 정렬
  • infinite scroll(무한 스크롤)
  • pull to refresh(당겨서 새로고침)
  • 게시물 좋아요, 댓글, 공유
  • 탐색 탭 전환

특징

  • 카드형 피드
  • 더블 탭으로 좋아요, 하트 애니메이션
  • 스크롤 방향에 따라 탭바 숨김/표시
3 게시물 목록 페이지

기능

  • 운동 종목/해시태그/장소별 게시물 모아보기
  • 인기순·최신순 정렬 전환
  • 키워드·닉네임 검색
  • 그리드 ↔ 리스트 뷰 전환

특징

  • 3열 그리드 기본, 사진 위주 레이아웃
  • 검색창 상단 고정(sticky)
4 게시물 상세 페이지

기능

  • 사진/영상 슬라이드(다중 업로드 시)
  • 운동 종목·장소·소요 시간 표시
  • 좋아요/댓글/공유, 댓글 대댓글
  • 작성자 프로필로 이동
  • 연결된 목표 진행률 표시
  • 본인 게시물 수정/삭제 메뉴

특징

  • 사진 아래 운동 정보 카드로 구분
  • 댓글은 하단 바텀시트로 펼쳐보기
5 게시물 작성 페이지

기능

  • 사진/영상 업로드(다중 선택)
  • 운동 종목·시간/거리 기록 입력
  • 장소 태그(GPS 연동 시 자동 추천)
  • 목표와 연결(달성 인증 게시물)
  • 공개 범위 설정(전체/팔로워만/나만 보기)

특징

  • 단계형(사진 선택 → 정보 입력 → 공개 설정) 작성 플로우
6 마이페이지

기능

  • 프로필(닉네임, 사진, 소개) 조회/수정
  • 내가 쓴 게시물 그리드
  • 팔로워/팔로잉 수 → 목록 페이지 이동
  • 목표 달성 현황 요약
  • 로그아웃, 회원 탈퇴, 알림/테마 설정

특징

  • 상단 프로필 + 하단 탭(게시물/목표)
  • 타인 프로필 조회 화면으로 레이아웃 재사용
7 목표 설정/관리 페이지 신규 추가

기능

  • 운동 목표 등록(종목, 목표치, 기간)
  • 목표별 진행률 트래킹(그래프/게이지)
  • 목표 달성 시 게시물 연결 인증
  • 목표 알림(리마인드) 설정

특징

  • 핵심 가치 "목표 지정 및 달성"을 담당하는 페이지 — 기존 목록에 빠져 있어 이번에 추가
8 알림 페이지 신규 추가

기능

  • 좋아요/댓글/팔로우/목표 달성 알림 목록
  • 안 읽은 알림 표시(뱃지)
  • 탭하면 관련 페이지로 바로 이동

특징

  • 인스타그램·X처럼 하단 탭바 별도 탭으로 배치 — 기존 기획엔 누락됐던 화면
9 팔로워/팔로잉 목록 페이지 신규 추가

기능

  • 팔로워/팔로잉 탭 전환
  • 목록에서 바로 팔로우/언팔로우
  • 닉네임 검색 필터링

특징

  • 마이페이지·타인 프로필에서 팔로워·팔로잉 수 탭 시 진입

4핵심 기능 정의

필수 기능

1회원가입/로그인 (이메일 기반) 2운동 기록 게시물 작성 및 팔로잉 피드 3목표 설정 및 달성률 트래킹

부가 기능

1PWA 2신고/차단 3GPS (장소 자동 태그·추천) 4목표 달성 알림/리마인드 5랭킹/주간 운동 통계 6알림함(좋아요·댓글·팔로우)

5모바일 UI 특징

네비게이션하단 탭바 4개(홈/탐색/알림/마이페이지) + 중앙 플로팅 작성(+) 버튼. 목표 페이지는 마이페이지 하위 탭(게시물/목표)으로 진입해 5탭+FAB의 과밀을 방지
주요 버튼 위치작성(+) 버튼은 하단 탭바 중앙 원형 플로팅 버튼, 좋아요/댓글/공유는 게시물 하단 가로 정렬
터치 영역 크기최소 44×44px 이상 확보, 엄지 조작이 쉬운 화면 하단 위주 배치
세로/가로 모드세로 모드 기본 지원, 사진/영상 상세 보기 시에만 가로 모드 허용

핵심 가치 확장목표 설정/관리 페이지, 마이페이지, 게시물 목록(탐색) 페이지, 팔로워/팔로잉 목록 페이지
