# 모바일 서비스 UI 기획서

## 1. 서비스 기본 정보

| 항목 | 내용 |
|---|---|
| 서비스 이름 | 트랙핏(TrackFit) |
| 서비스 주제 | 자신들만의 운동 기록을 공유 |
| 핵심 가치 | 운동할 장소 공유 및 자신의 목표 지정 및 달성 |
| 타겟 사용자 | 20~40대 |

## 2. 디자인 컨셉

| 항목 | 내용 |
|---|---|
| 메인 색상 | `docs/미니 SNS 프로젝트/style_theme` (Material 3 기반, Primary `#415F91` 블루 계열) — `light.css` / `dark.css`로 라이트·다크 모드 모두 정의됨 |
| 전체 분위기 | 깔끔하고 전문적인 분위기 |
| 참고 사이트 | 인스타그램, X(구 트위터) |
| 접근성 지원 | `style_theme` 폴더에 라이트/다크 각각 표준·중간대비(`-mc`)·고대비(`-hc`) 3단계 테마가 준비되어 있음. 실외에서 운동하며 사용하는 서비스 특성상 햇빛 아래 가독성을 위해 설정(마이페이지)에서 고대비 모드를 선택할 수 있게 노출 권장 |

## 3. 필요한 페이지 목록

### 1. 로그인/회원가입 페이지
- **기능**
  - 이메일 + 패스워드 로그인
  - 이메일 회원가입(이메일 인증 X)
  - 닉네임(이름)
  - 생년월일(만 14세 미만 가입 금지)
  - 자동 로그인(토큰 저장)
  - 비밀번호 재설정(이메일로 재설정 링크 발송)
  - 이용약관/개인정보처리방침 동의 체크박스(필수, 생년월일 기반 만 14세 확인과 연계)
- **특징**
  - 회원가입 후 로그인 페이지에서 로그인 시도
  - 로그인 성공 시 메인 피드로 이동
  - 앱 최초 실행 시 간단한 온보딩(서비스 소개 2~3장) 후 로그인/회원가입 화면 노출

### 2. 메인 페이지 (홈 화면)
- **기능**
  - 팔로잉 기반 피드 - 최신순 정렬
  - infinite scroll(무한 스크롤)
  - pull to refresh(당겨서 새로고침)
  - 게시물 좋아요, 댓글, 공유
  - 탐색 탭 전환
- **특징**
  - 카드형 피드
  - 더블 탭으로 좋아요, 하트 애니메이션
  - 스크롤 방향에 따라 탭바 숨김/표시

### 3. 게시물 목록 페이지 (탐색/검색 결과)
- **기능**
  - 운동 종목/해시태그/장소별 게시물 모아보기
  - 인기순·최신순 정렬 전환
  - 키워드·닉네임 검색
  - 그리드(썸네일) 뷰 ↔ 리스트 뷰 전환
- **특징**
  - 3열 그리드 기본, 사진 위주 레이아웃
  - 검색창 상단 고정(sticky)

### 4. 게시물 상세 페이지
- **기능**
  - 사진/영상 슬라이드(여러 장 업로드 시)
  - 운동 종목, 장소, 소요 시간 등 운동 정보 표시
  - 좋아요/댓글/공유, 댓글 대댓글
  - 작성자 프로필로 이동
  - 연결된 목표가 있을 경우 목표 진행률 표시
  - 본인 게시물인 경우 수정/삭제 메뉴 노출
- **특징**
  - 사진 아래 운동 정보 카드 형태로 구분
  - 댓글은 하단 바텀시트로 펼쳐보기

### 5. 게시물 작성 페이지
- **기능**
  - 사진/영상 업로드(다중 선택)
  - 운동 종목 선택, 운동 시간/거리 등 기록 입력
  - 장소 태그(GPS 부가 기능 연동 시 자동 추천)
  - 목표와 연결(목표 달성 인증 게시물로 등록)
  - 공개 범위 설정(전체/팔로워만/나만 보기)
- **특징**
  - 인스타그램 스타일의 단계형(사진 선택 → 정보 입력 → 공개 설정) 작성 플로우

### 6. 마이페이지
- **기능**
  - 프로필(닉네임, 프로필 사진, 소개) 조회/수정
  - 내가 쓴 게시물 그리드
  - 팔로워/팔로잉 수 클릭 시 목록 페이지로 이동(9번 페이지)
  - 목표 달성 현황 요약(진행 중/완료 목표 개수 등)
  - 로그아웃, 회원 탈퇴, 알림 설정, 다크모드/고대비 모드 설정
- **특징**
  - 상단 프로필 영역 + 하단 탭(게시물/목표)으로 구성
  - 동일한 레이아웃을 다른 사용자 프로필 조회 화면으로도 재사용(본인 화면엔 "프로필 수정" 버튼, 타인 화면엔 "팔로우/팔로잉" 버튼 노출)

### 7. 목표 설정/관리 페이지 *(핵심 가치 반영을 위해 추가)*
- **기능**
  - 운동 목표 등록(종목, 목표치, 기간 설정)
  - 목표별 진행률 트래킹(그래프/게이지)
  - 목표 달성 시 게시물과 연결해 인증
  - 목표 알림(리마인드) 설정
- **특징**
  - 핵심 가치인 "목표 지정 및 달성"을 담당하는 페이지로, 기존 목록에는 빠져 있어 이번에 추가함

### 8. 알림 페이지 *(참고 사이트 대비 누락되어 추가)*
- **기능**
  - 좋아요/댓글/팔로우/목표 달성 알림 목록(최신순)
  - 안 읽은 알림 표시(뱃지, 굵은 글씨 등)
  - 알림 탭하면 관련 게시물/프로필/목표 페이지로 바로 이동
- **특징**
  - 인스타그램·X처럼 하단 탭바의 별도 탭으로 배치(기존 기획에는 알림 탭·페이지가 없었음)

### 9. 팔로워/팔로잉 목록 페이지
- **기능**
  - 팔로워 목록 / 팔로잉 목록 탭 전환
  - 목록에서 바로 팔로우/언팔로우
  - 닉네임 검색으로 목록 내 필터링
- **특징**
  - 마이페이지 및 타인 프로필 화면에서 팔로워·팔로잉 수를 탭하면 진입

## 4. 핵심 기능 정의

### 필수 기능 (꼭 있어야 하는 기능)
1. 회원가입/로그인 (이메일 기반)
2. 운동 기록 게시물 작성 및 팔로잉 피드
3. 목표 설정 및 달성률 트래킹

### 부가 기능 (있으면 좋은 기능)
1. PWA
2. 신고/차단
3. GPS (운동 장소 자동 태그, 주변 운동 장소 추천)
4. 목표 달성 알림/리마인드
5. 랭킹/주간 운동 통계
6. 알림함(좋아요·댓글·팔로우 알림)

## 5. 모바일 UI 특징

| 항목 | 내용 |
|---|---|
| 네비게이션 | 하단 탭바 4개(홈/탐색/알림/마이페이지) + 중앙 플로팅 작성(+) 버튼, 상세 페이지는 상단에 뒤로가기 아이콘만 배치. 목표 페이지는 별도 탭 없이 마이페이지 하위 탭(게시물/목표)으로 진입 — 탭바에 목표를 따로 두면 5탭+FAB로 과밀해지는 것을 방지 |
| 주요 버튼 위치 | 게시물 작성(+) 버튼은 하단 탭바 중앙에 원형 플로팅 버튼으로 배치, 좋아요/댓글/공유는 게시물 하단에 가로 정렬 |
| 터치 영역 크기 | 최소 44x44px 이상 확보(엄지로 조작하기 쉬운 화면 하단 위주 배치) |
| 세로/가로 모드 | 세로 모드 기본 지원, 사진/영상 상세 보기 시에만 가로 모드 허용 |

## 6. 개발 우선순위

- **1차 개발**: 로그인/회원가입, 메인 피드(홈), 게시물 작성/상세 페이지
- **2차 개발**: 목표 설정/관리 페이지, 마이페이지, 게시물 목록(탐색) 페이지, 팔로워/팔로잉 목록 페이지
- **3차 개발**: 알림 페이지, PWA, GPS 장소 태그·추천, 신고/차단, 랭킹/통계, 목표 알림
