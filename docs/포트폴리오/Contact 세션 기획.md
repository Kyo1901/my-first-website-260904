# Contact 섹션 기획서

## 프로젝트 정보
- **섹션명**: Contact (연락처 & 방명록)
- **참고 문서**: `Contact 세션 기획.txt` (설문 원본)
- **참고 이미지**: `방명록 참고.png`
- **적용 프로젝트**: 포트폴리오 웹사이트

## 1. 전체 컨셉

| 항목 | 결정 사항 |
|---|---|
| 전체 느낌 | 친근하고 따뜻한 느낌 |
| 이메일/연락처 표시 | 아이콘 + 텍스트 정렬 |
| SNS 링크 스타일 | 동그란 아이콘 버튼들을 나란히 배치 |
| 색상 분위기 | 포트폴리오 컬러 팔레트 참고 (`컬러 팔레트 디자인 시스템.md`) |
| 전체 배치 | 좌우 2단 배치 |

## 2. 레이아웃 구조

참고 이미지(`방명록 참고.png`)의 좌/우 2단 구성을 기반으로 하되, 좌우 배치를 아래와 같이 지정한다.

```
┌─────────────────────────────────────────────┐
│                Contact 섹션                   │
├───────────────────────┬───────────────────────┤
│                       │                       │
│   왼쪽: 방명록 작성 폼    │   오른쪽: 연락처 정보     │
│   - 이름 입력           │   - 아이콘 + 텍스트 연락처  │
│   - 이메일 입력          │   - SNS 아이콘 버튼(원형)  │
│   - 메시지 입력          │                       │
│   - 별점 선택           │                       │
│   - 등록 버튼           │                       │
│                       │                       │
├───────────────────────┴───────────────────────┤
│              아래: 방명록 리스트                  │
│   (등록된 방명록을 카드 형태로 순서대로 출력)          │
└─────────────────────────────────────────────┘
```

- **왼쪽**: 방명록 작성 폼
- **오른쪽**: 연락처(이메일, SNS 등) 정보
- **하단**: 등록된 방명록 리스트 전체 출력

## 3. 색상 가이드

기존 `컬러 팔레트 디자인 시스템.md`의 CSS 변수를 그대로 사용한다.

- 섹션 배경: `--color-bg-secondary` (#F8EEE1)
- 폼 입력 필드/카드 표면: `--color-secondary` (#F8EEE1) 계열
- 강조(등록 버튼, 별점 활성 등): `--color-accent` (#8490C8)
- 본문 텍스트: `--color-text-primary` (#292929)
- 보조 텍스트(날짜 등): `--color-text-muted` (#8A8A8A)
- 버튼 hover: `--color-button-hover` (#DFD6CB)

## 4. 방명록 데이터 구조

### 4.1 필수 항목
| 필드 | 설명 |
|---|---|
| 방명록 ID | 자동 생성 번호 |
| 작성자 이름 | 사용자 입력 |
| 방명록 내용/메시지 | 사용자 입력 |
| 작성 날짜/시간 | 자동 기록 |

### 4.2 선택 항목
| 필드 | 설명 | 비고 |
|---|---|---|
| 이메일 주소 | 사용자 입력 | 비공개로 저장 (리스트에는 노출 안 함) |
| 별점 평가 | 사용자 입력 | 재미 요소로 포함 |

### 4.3 이번 기획에서 제외된 항목
- 전화번호
- SNS 계정
- 소속/직업, 거주 지역, 나이대, 유입 경로
- 좋아하는 색깔, 한마디 키워드, 이모지 선택

> 필요 시 추후 확장 가능하도록 데이터 스키마는 여유를 두고 설계한다.

## 5. 폼 입력 항목 (정리)

1. 이름 (필수)
2. 이메일 (필수, 비공개 저장)
3. 방명록 메시지 (필수)
4. 별점 평가 (선택 UI, 예: 1~5점)
5. 등록 버튼

## 6. 연락처 영역 구성

- 아이콘 + 텍스트 형식으로 이메일/연락처 정보 노출
- SNS 링크는 원형 아이콘 버튼으로 나란히 배치
- `방명록 참고.png`의 "Call Us / Email Us / Website / Address" 구성을 참고하되, 보유한 연락 채널에 맞춰 항목 선정

## 7. 방명록 리스트 영역

- Contact 섹션 하단에 전체 폭으로 배치
- 카드 형태로 방명록 항목 나열 (이름, 날짜, 메시지, 별점 표시)
- 이메일은 비공개이므로 리스트에는 표시하지 않음
