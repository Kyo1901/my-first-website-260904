```css
:root {
  /* Primary Colors */
  --color-primary: #FC9C84;
  --color-primary-light: #FDB09D;
  --color-primary-dark: #CA7D6A;

  /* Secondary Colors */
  --color-secondary: #F8EEE1;
  --color-accent: #8490C8;

  /* Background Colors */
  --color-bg-primary: #FC9C84;
  --color-bg-secondary: #F8EEE1;

  /* Text Colors */
  --color-text-primary: #292929;
  --color-text-secondary: #B06F4F;
  --color-text-muted: #8A8A8A;

  /* Interactive Colors */

  --color-link-hover: #707AAA;
}
```

## 컬러 사용 가이드

### Primary Colors
- **`--color-primary` (#FC9C84)**: 히어로 섹션, 페이지 상단 배경 등 사이트의 첫인상을 결정하는 넓은 면적에 사용. 브랜드의 에너지와 톤을 대표하는 색상이므로 과도하게 여러 곳에 나눠 쓰기보다 한두 개의 큰 블록에 집중적으로 사용
- **`--color-primary-light` (#FDB09D)**: primary 위에 얹는 서브 요소(카드 배경, hover 시 배경 틴트, 섹션 구분용 연한 배경)에 사용해 톤을 유지하면서 대비를 완화
- **`--color-primary-dark` (#CA7D6A)**: primary 색상 위에서도 대비가 필요한 텍스트, 아이콘 외곽선, 강조 보더 등에 사용

### Secondary & Accent Colors
- **`--color-secondary` (#F8EEE1)**: 헤더/푸터 내비게이션 바, 카드·버튼 등 콘텐츠를 담는 "그릇" 역할의 표면(surface) 색상. 채도가 낮아 어떤 콘텐츠와도 무난하게 어울림
- **`--color-accent` (#8490C8)**: 사용자의 행동을 유도하는 지점(모달, CTA 배지, 주요 아이콘)에만 제한적으로 사용. 배경 대비 채도·명도 차이가 커서 시선을 확실히 붙잡는 포인트 컬러이므로 전체 화면의 5~10% 이내로 절제해서 사용 권장

### Background Colors
- **`--color-bg-primary` (#FC9C84)**: 페이지의 기본 배경(예: 히어로, 랜딩 섹션)
- **`--color-bg-secondary` (#F8EEE1)**: 헤더, 푸터 바로 위, 카드/모달 등 콘텐츠 블록의 배경. bg-primary와 명도 대비가 뚜렷해 섹션 구분이 자연스럽게 이루어짐

### Text Colors
- **`--color-text-primary` (#292929)**: 헤드라인, 본문 등 가장 중요한 텍스트. 거의 블랙에 가까워 밝은 배경 위에서 가독성이 가장 높음
- **`--color-text-secondary` (#B06F4F)**: 내비게이션 메뉴, 서브 헤드라인 등 primary보다 한 단계 낮은 중요도의 텍스트. 웜톤이라 크림 배경과 자연스럽게 어울림
- **`--color-text-muted` (#8A8A8A)**: 캡션, 타임스탬프, 비활성 상태 텍스트 등 시각적 우선순위가 가장 낮은 정보에 사용

### Interactive Colors
- **`--color-button-primary` (#F8EEE1)**: 기본 버튼 배경. 텍스트는 `--color-text-primary`(#292929)를 조합해 사용
- **`--color-button-hover` (#DFD6CB)**: 버튼 hover/active 상태. 기본 버튼 색보다 살짝 어둡게 해서 클릭 피드백을 명확히 전달
- **`--color-link` (#8490C8)**: 본문 내 링크, 강조 텍스트. accent 컬러와 동일하게 맞춰 "클릭 가능한 요소는 이 색"이라는 일관된 인지 패턴을 형성
- **`--color-link-hover` (#707AAA)**: 링크 hover 시 더 진한 톤으로 전환해 상태 변화를 인지시킴

### 브랜드 포인트 컬러 (참고용)
원본 사이트 로고 및 "OK DRUGS" 반복 텍스트에는 아래 5색 그라데이션이 사용되었습니다. 메인 시스템 색상은 아니지만, 일러스트/뱃지/태그 등 브랜드 시그니처가 필요한 요소에 제한적으로 활용할 수 있습니다.

| 색상 | Hex |
|---|---|
| Red | `#E9745F` |
| Coral | `#F49480` |
| Gold | `#FABE6E` |
| Olive | `#A0A06E` |
| Periwinkle | `#8490C8` |

## 반응형 고려사항

### 다크모드
현재 팔레트는 밝은 배경(코랄, 크림) 중심으로 설계되어 있어, 다크모드 적용 시 명도를 반전하되 색상의 색조(Hue)는 유지하는 방식을 권장합니다.

```css
@media (prefers-color-scheme: dark) {
  :root {
    --color-bg-primary: #3A2A24;      /* 코랄의 저명도 버전 */
    --color-bg-secondary: #2A2622;     /* 크림의 저명도 버전 */
    --color-text-primary: #F5EFEA;     /* 밝은 텍스트로 반전 */
    --color-text-secondary: #E0B39A;   /* 웜 브라운을 밝게 */
    --color-text-muted: #9A9A9A;
    --color-primary: #E28A6E;          /* 다크 배경에서도 시인성 확보 */
    --color-accent: #9AA6D8;           /* 페리윙클을 살짝 밝게 조정 */
    --color-button-primary: #4A423A;
    --color-button-hover: #5A5048;
  }
}
```
- `data-theme="dark"` 속성을 쓰는 수동 토글 방식이라면 `:root[data-theme="dark"]`에 동일한 값을 한 번 더 정의해 시스템 설정과 사용자 선택이 모두 반영되도록 구성
- 색상을 반전할 때도 accent(#8490C8)의 색조는 유지해 브랜드 정체성이 끊기지 않도록 함

### 접근성(대비)
- `--color-text-primary`(#292929)를 `--color-bg-primary`(#FC9C84) 위에 직접 올릴 경우 대비가 다소 낮으므로, 본문 텍스트에는 카드/모달 등 밝은 `--color-bg-secondary` 위에서만 사용 권장
- 버튼/링크 텍스트는 항상 WCAG AA 기준(일반 텍스트 4.5:1) 이상을 만족하는 조합인지 실제 배경에서 확인 후 사용

### 화면 크기별 적용
- **모바일**: primary 컬러 블록의 면적을 줄이고 bg-secondary(크림) 비중을 높여 콘텐츠 가독성 우선
- **태블릿/데스크톱**: 원본 디자인처럼 primary(코랄)를 배경 전체에 넓게 사용하고, 카드·모달에 bg-secondary와 accent를 배치해 시각적 리듬 형성
- 이미지/미디어가 많은 섹션에서는 accent 컬러 사용을 최소화해 실제 콘텐츠(사진)의 색감과 충돌하지 않도록 함
