## 3. 컬러 사용 가이드

### Primary / Secondary / Tertiary
- **Primary·On Primary**: 핵심 CTA 버튼, 주요 브랜드 강조 요소. 버튼 배경에 `--md-primary`, 버튼 텍스트/아이콘에 `--md-on-primary` 조합으로 사용
- **Primary Container·On Primary Container**: Primary보다 톤을 낮춘 강조 영역(배지, 선택된 탭, 하이라이트 카드)에 사용. 배경은 Container, 텍스트는 On Container
- **Secondary**: Primary를 보조하는 액션(보조 버튼, 필터 칩)에 사용해 화면의 시각적 위계를 정리
- **Tertiary**: 대비 포인트가 필요한 부가 요소(알림 뱃지, 인포그래픽 강조)에 제한적으로 사용

### Error
- **Error·On Error**: 폼 유효성 검사 실패, 삭제 버튼 등 위험/경고 액션
- **Error Container·On Error Container**: 에러 메시지 박스, 경고 배너처럼 상시 노출되지만 톤은 낮춰야 하는 영역

### Surface 계열
- **Surface**: 페이지의 기본 배경색
- **Surface Dim / Surface Bright**: Surface보다 어둡거나 밝은 변형. 섹션 간 미묘한 명도 구분이 필요할 때 사용
- **Surface Container (Lowest → Highest)**: 카드, 모달, 시트 등 "떠 있는" 요소의 배경. 계층이 높을수록(Highest) 배경 위로 더 도드라지게 표현할 때 사용 (예: Lowest = 페이지에 가장 밀착된 카드, Highest = 팝업/다이얼로그)
- **On Surface·On Surface Variant**: On Surface는 본문 텍스트 등 최우선 정보, On Surface Variant는 캡션·보조 라벨 등 우선순위가 낮은 텍스트

### Outline
- **Outline**: 입력 필드 테두리, 구분선 등 명확한 경계가 필요한 곳
- **Outline Variant**: 장식적인 구분선, 비활성 상태의 옅은 테두리

### Inverse (반전 컬러)
- 툴팁, 스낵바(Snackbar)처럼 현재 테마와 반대되는 배경 위에 콘텐츠를 띄울 때 사용
- `--md-inverse-surface` 배경 + `--md-inverse-on-surface` 텍스트 + 필요 시 `--md-inverse-primary`로 강조 버튼/링크 표시

### Scrim & Shadow
- **Scrim**: 모달/드로어 오픈 시 뒷배경을 어둡게 덮는 반투명 오버레이 (`rgba(0,0,0,0.4)` 등으로 투명도 조절해 사용)
- **Shadow**: 박스 섀도우의 베이스 컬러. `box-shadow: 0 2px 8px rgba(0,0,0,0.15)`처럼 투명도를 조절해 사용

## 4. 라이트 ↔ 다크 대응 규칙 (참고)

두 이미지를 분석한 결과, Material 3 톤 팔레트 특유의 대응 관계가 그대로 유지되고 있음을 확인했다.

- 라이트의 `Container` 계열 색상 ≈ 다크의 `On Container` 계열 색상 (예: 라이트 Primary Container `#FFDAD2` = 다크 On Primary Container `#FFDAD2`)
- 라이트의 `On Container` 계열 색상 ≈ 다크의 `Container` 계열 색상 (예: 라이트 On Primary Container `#723425` = 다크 Primary Container `#723425`)
- 라이트 Primary `#8F4B3A` = 다크 Inverse Primary `#8F4B3A`, 다크 Primary `#FFB4A2` = 라이트 Inverse Primary `#FFB4A2`

새로운 테마 변형을 추가하거나 색상을 조정할 때 이 대응 규칙을 참고하면 라이트/다크 세트를 일관되게 유지할 수 있다.

## 5. 접근성(대비) 체크리스트

- 본문 텍스트: `--md-on-surface` on `--md-surface` 조합 사용 (라이트: `#231917` on `#FFF8F6`, 다크: `#F1DFDA` on `#1A110F` → 두 조합 모두 WCAG AA 이상의 명도 대비 확보)
- 버튼 텍스트: `--md-on-primary` on `--md-primary` 조합을 실제 배경에서 대비 확인 후 사용 (라이트는 흰 텍스트, 다크는 짙은 텍스트로 역할이 바뀌는 점 유의)
- 에러 메시지: `--md-on-error-container` on `--md-error-container` 조합 사용, 저시력 사용자를 위해 텍스트 크기와 함께 아이콘 등 보조 표시 병행 권장

## 6. 반응형/적용 가이드

- **모바일**: Surface Container 계열(카드, 바텀시트)의 사용 빈도가 높아지므로 Lowest~Highest 단계를 명확히 구분해 터치 영역의 계층을 표현
- **다크모드 전환**: `data-theme` 속성을 이용한 수동 토글과 `prefers-color-scheme` 자동 감지를 함께 지원하며, 토글 시 두 정의가 충돌하지 않도록 `:root:not([data-theme="light"])` 셀렉터로 우선순위를 관리
- **기존 팔레트와 병행**: `컬러 팔레트 디자인 시스템.md`의 브랜드 포인트 컬러(그라데이션 5색)는 일러스트/뱃지 등 시그니처 요소에, 본 문서의 Material 3 토큰은 UI 컴포넌트 전반의 상태/역할 표현에 사용하는 방식으로 역할을 분리해 활용 가능
