# Novel Story 기획서

## 1. 프로젝트 개요
- **커뮤니티 주제**: 소설/잡지 정보 공유
- **사이트 이름**: Novel Story
- **분위기**: 친근하고 유쾌한 분위기
- **참고 사이트**
  - 네이버 카페 → 게시판 카테고리 구조, 댓글/대댓글 UI
  - 교보문고 → 도서 정보 카드 UI(표지 이미지 + 평점 + 태그 형태)

## 2. 디자인 스타일
- **Primary Color**: 파스텔톤의 푸른색
- **Secondary Color**: 오프화이트/크림 (배경·카드 등 콘텐츠를 담는 용도)
- **Accent Color**: 코럴/피치 계열 (좋아요·평점·CTA 버튼 등 포인트 요소에만 제한적으로 사용)
- **폰트 컨셉**: 각진 느낌보다 둥글고 부드러운 고딕 계열(예: Pretendard) — "친근하고 유쾌한" 분위기와 통일감

## 3. 데이터 모델 개요
게시글마다 소설/잡지 제목을 자유 텍스트로 입력받지 않고, **소설/잡지 마스터 데이터**를 별도로 관리한다. 이렇게 하면 "소설별 평균 평점", "같은 소설을 다룬 글 모아보기" 같은 기능이 자연스럽게 구현된다.

- **소설/잡지 테이블**: 제목, 작가/출판사, 장르, 표지 이미지, 평균 평점(집계)
- **게시글 테이블**: 제목, 본문, 작성자, 작성일, 좋아요 수, 연결된 소설/잡지(FK)
- **댓글 테이블**: 게시글(FK), 작성자, 내용, 작성 시간, 상위 댓글(FK, 대댓글용), 좋아요 수
- **평점 테이블**: 소설/잡지(FK), 작성자(FK), 점수 — 사용자 1명당 소설 1개에 평점 1개만 남기도록 유니크 제약
- **좋아요 테이블**: 대상(게시글/댓글), 작성자(FK) — 중복 방지를 위한 유니크 제약, 다시 누르면 취소(토글)
- **신고 테이블**: 대상(게시글/댓글), 신고자(FK), 사유, 처리 상태

게시글 작성 시 소설/잡지는 **검색 후 선택**하며, 목록에 없으면 그 자리에서 새로 등록할 수 있도록 한다.

## 4. 페이지별 기능 명세

### 4.1 회원가입 페이지
- 이메일(계정) — **가입 확인 메일 절차 없이, 중복 여부만 검사하여 즉시 가입 처리**
- 비밀번호 (최소 8자 이상 권장)
- 비밀번호 확인(오타 검증용)
- 닉네임(이름) — 중복 확인 필요
- 회원가입 버튼

> 전화번호는 실제 본인인증에 사용하지 않는 한 불필요한 개인정보 수집이 되므로 수집 항목에서 제외한다.

### 4.2 로그인 페이지
- 이메일(계정) 입력
- 비밀번호 입력
- 로그인 버튼
- 회원가입 버튼
- 비밀번호 찾기 버튼 → 클릭 시 가입한 이메일로 비밀번호 재설정 링크 발송 → 링크 클릭 시 새 비밀번호 입력 페이지로 이동

### 4.3 게시물 목록 페이지
- 검색창(소설/잡지 제목, 작성자 검색)
- 정렬 옵션(최신순 / 인기순 / 평점순)
- 게시글 카드
  - 게시글 제목
  - 소설/잡지 제목(+ 표지 썸네일)
  - 작성자
  - 작성 날짜
  - 좋아요 수
  - 댓글 수
  - 최근 댓글(2개)
- 페이지네이션(페이지 번호 방식)

### 4.4 게시글 작성/수정 페이지
- 소설/잡지 검색 후 선택(없으면 신규 등록)
- 게시글 제목
- 게시글 내용(본문)
- 이미지 첨부(선택)
- 등록/수정 버튼
- 본인 글에 한해 수정·삭제 가능

### 4.5 게시물 상세 페이지
- 게시글 제목
- 작성자
- 작성 날짜
- 게시글 내용(본문)
- 연결된 소설/잡지 정보 + 평균 평점
- 좋아요 수 + 좋아요 버튼(토글)
- 신고 버튼
- 본인 글일 경우 수정·삭제 버튼
- 댓글 영역

### 4.6 댓글 기능
- 댓글 작성자, 내용, 작성 시간
- 댓글 좋아요(토글)
- 대댓글(1단계까지만 허용)
- 본인 댓글 수정·삭제
- 댓글 신고

### 4.7 소설/잡지 평점 기능
- 소설/잡지 상세 정보 영역에서 별점(5점 만점) 등록
- 사용자 1명당 소설 1개에 평점 1회만 등록 가능(재평가 시 기존 점수 수정)
- 평균 평점은 목록/상세 화면에 함께 노출

### 4.8 마이페이지
- 내가 쓴 게시글 목록
- 내가 쓴 댓글 목록
- 내가 좋아요한 게시글 목록
- 내가 남긴 평점 히스토리
- 프로필 수정(닉네임 변경)
- 회원 탈퇴

### 4.9 관리자 페이지
- 신고 목록 확인 및 처리(게시글/댓글 삭제, 신고 반려)
- 회원 목록 관리(제재/탈퇴 처리)
- 소설/잡지 마스터 데이터 관리(중복 항목 정리)

### 4.10 정책 페이지
- 이용약관
- 개인정보처리방침(수집 항목: 이메일, 닉네임, 비밀번호)
